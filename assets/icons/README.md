# Iconos

Los iconos de interfaz son SVG externos cargados con `<img>`:

- `heart-outline.svg`: favorito inactivo.
- `heart-filled.svg`: favorito activo.
- `external-link.svg`: enlace al sitio oficial del municipio.
- `favicon.svg`: favicon y marca de cabecera.

Los tres iconos de interfaz proceden de Bootstrap Icons 1.11.3, bajo licencia
MIT: <https://github.com/twbs/icons/blob/main/LICENSE>. El favicon es una
composición propia.

Al sustituir iconos, conserva los nombres de archivo para no cambiar las
referencias de `index.html`.
